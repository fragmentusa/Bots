GIFTTRANSFER — DEPLOY НА RENDER

1) Создай Telegram-бота через @BotFather и включи Inline Mode:
   /setinline

2) Создай GitHub-репозиторий и загрузи в него все файлы из этой папки.

3) На Render выбери New → Blueprint и подключи репозиторий.
   Render прочитает render.yaml и создаст Web Service.

4) В настройках Environment заполни:
   BOT_TOKEN     — токен от BotFather (никому не отправляй)
   ACCESS_CODE   — придумай длинный секретный код
   BOT_USERNAME  — username бота без @

   WEBHOOK_SECRET Render сгенерирует автоматически.

5) Нажми Deploy. После запуска открой адрес Render — должно появиться:
   GiftTransfer bot is running

6) Открой бота в Telegram, отправь /start, затем секретный ACCESS_CODE.
   В inline-запросе используй:
   @ТВОЙ_БОТ https://t.me/nft/SLUG 100 stars ru

ПОДДЕРЖИВАЕМЫЕ ЗНАЧЕНИЯ:
   Валюта: stars, gram, rub
   Язык:   ru, en, zh

ВАЖНЫЕ ОГРАНИЧЕНИЯ БЕСПЛАТНОГО RENDER:
- Бесплатный Web Service засыпает после периода без входящего трафика.
  Бот может отвечать с задержкой после пробуждения.
- Файловая система бесплатного сервиса временная. SQLite в /tmp может
  сброситься после перезапуска или нового деплоя. Выданные доступы могут
  потеряться. Для постоянного хранения нужна внешняя БД или платный диск.
- Для Telegram inline-бота стабильная постоянная работа предпочтительнее
  на хостинге с постоянно работающим процессом и постоянной БД.

БЕЗОПАСНОСТЬ:
- Никогда не публикуй BOT_TOKEN и ACCESS_CODE.
- Этот проект не хранит/не переводит NFT или деньги и не подтверждает
  передачу подарков. Кнопка проверки честно сообщает, что интеграция
  проверки не подключена. Не обещай пользователям эскроу или выплату.
